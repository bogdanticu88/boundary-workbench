01 / Purpose and open decisions

Mock acceptance exercise only. A central harness delegates to a read-only PR reviewer and a sandbox security-testing agent. All systems, identities and evidence are fictional. No scanning is performed.

Design owner: Unassigned · Security reviewer: Unassigned

Assumptions: Design-stage declarations only. Azure sandbox, synthetic repositories and targets. The PR reviewer cannot execute code; the testing agent can execute code with a scoped sandbox credential.

Exclusions: No production access, real customer data, real targets, or regulatory compliance conclusion.
